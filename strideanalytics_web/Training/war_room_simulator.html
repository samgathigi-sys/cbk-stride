Level 2 Focus: RAM / Volatile Memory (The Investigator's Goldmine)

Modern financial malware (like Cobalt Strike or in-memory API hooks) executes purely in RAM without writing an executable file to disk (Fileless Malware). If a junior admin reboots the server, the encryption keys, running processes, and evidence of who authorized the fraudulent transfer are wiped clean.

Correct Action: Use a tool like DumpIt, WinPmem, or LiME to capture a full raw memory snapshot (`memory.raw`) BEFORE touching any services or cables!
